# Installation Guide

## Before installation

- Use a Windows computer and desktop Microsoft Excel with VBA support.
- Obtain the workbook from a source you trust.
- Check that the downloaded file is the intended release.
- Back up any existing workbook and business data before replacing files.

## Install

1. Download the approved release package.
2. Extract the ZIP archive to a normal local folder. Do not run the workbook from inside the ZIP preview.
3. Keep the workbook and any release companion files together.
4. Open `IMS-v1.1.0.xlsm` in desktop Microsoft Excel.
5. Read any Office security prompts. Only enable macros if you have verified the file's source and trust it.
6. Follow the first-run or setup process displayed by the application.

## Notes

- Excel for the web does not run desktop VBA macros in the same way as Excel desktop.
- Exact supported Windows and Excel versions must be confirmed by testing the actual release.
- Do not install over the only copy of a workbook containing business records.
- If the workbook fails to open, record the Excel version and the exact error message. Do not share passwords or business records in a public issue.
